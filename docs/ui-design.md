# SeisCanvas 界面视觉规范

适用于应用外壳、侧栏、层位管理、项目菜单、导入和导出窗口。沿用现有原生 CSS 和深蓝／灰白配色，不引入第二套组件库。

规范入口为 `frontend/src/style.css` 的 `:root`；侧栏通过 `frontend/src/sidebar.css` 的 `--panel-*` 别名引用公共规范。

## 字体与信息层级

| 用途 | 字号变量 | 字号 | 常用字重 |
| --- | --- | --- | --- |
| 弹窗标题 | `--font-heading` | 18px | 600 |
| 名称、表单值、操作、分组标题 | `--font-body` | 14px | 400／500／600 |
| 数量、单位、表头、说明与次要状态 | `--font-caption` | 12px | 400／500 |

通用界面维持上述三档；侧栏新增 `--font-compact: 13px` 用于选项、输入值和文件名，字段标签与辅助信息使用 12px，分组标题使用 14px／600。全应用最多四档，最低 12px。通过字重、灰阶和留白区分更多层级。

侧栏地图参数按“数据与比较”和“显示与色标”两块排列，以细分隔线和组间留白区分。统计项采用紧凑的名称／数值对齐，避免与可编辑字段争夺注意力。

科学图件中的坐标轴、标注和用户设置的导出字号独立于界面字号规范；不通过全局 SVG 或 canvas 规则覆盖它们。

## 颜色、描边与状态

- 表面使用 `--surface`，分区使用 `--surface-subtle`，页面背景使用 `--bg`。
- 主要动作使用 `--primary`，选中状态使用 `--primary-soft`；普通文字、次要文字分别使用 `--text`、`--text-secondary`、`--text-muted`。
- 描边统一引用 `--stroke-hairline: 0.5px`。浏览器会按设备像素比栅格化；低分屏可能显示为一个物理像素。
- 保留清晰的键盘焦点轮廓；焦点轮廓是可访问性反馈，不作为容器描边处理。
- 禁用态、错误态与真实操作状态对应。项目选中行使用底色，不增加左侧装饰彩条。
- 原始振幅、色阶、插值、层位颜色值和图件导出参数不属于本规范的调整范围。

## 间距与控件

常用间距为 4／8／12／16／24px，分别对应 `--space-1` 至 `--space-5`。表格密集内容优先 8／12px，弹窗主要区域优先 16／24px。侧栏控件保持 32px 高，弹窗表单一般 36px 高。

信息数量与名称通过留白分开；元数据可使用 `.meta-inline`、`.meta-count`，必要时使用 `.meta-divider`。不使用中点作为文案分隔符。单位写入括号，例如“线宽（pt）”。

保留解释操作影响、单位和错误原因的必要说明，避免重复的说明书式副标题。

## 圆角与阴影

| 用途 | 变量 | 数值 |
| --- | --- | --- |
| 小色块与浅色内容底 | `--radius-inset` | 2px |
| 按钮、输入框 | `--radius-control` | 6px |
| 小浮层、分段容器 | `--radius-popover` | 8px |
| 对话框 | `--radius-dialog` | 12px |

紧邻的嵌套控件按“内圆角 = 外圆角 − 内边距”处理，例如侧栏分段按钮与导出格式选择器。表格与分区保持平整，避免层层卡片化。阴影仅用于浮层、加载提示和窗口层级，引用 `--shadow-sm`、`--shadow-md`；贴右侧抽屉使用同等强度的定向阴影。

滚动区域为内容提供空间，标题和主要操作保持可见。层位管理列表及导出队列预留滚动槽，避免出现滚动条时宽度跳动。

## 层位管理

- 页面分为“分组管理 / 层位对应 / 统一配色”，每页只处理一类操作。分组导航仅在前两页出现，配色页展示跨分组对应表。
- 分组页提供“全部文件”入口，允许跨分组勾选；批量工具在选中文件后出现，可归入已有或新分组，也可移至未分组。分组后可直接进入对应页。
- 对应页支持搜索文件或层位、只看未对应文件，并区分已对应、未对应与重复对应。批量方式与参照分组分别选择；批量填写必须先预览当前文件、参照文件和目标层位，再应用。预览未处理时禁用切页与保存，避免误以为已生效。
- 配色页按统一层位管理颜色，明确标出没有对应文件的分组，并提供返回对应页的入口。
- 标题 18px，页签和区域标题 14px，文件名／表单值／按钮 13px，表头／数量／说明 12px。选中行使用浅蓝底色，表格不套多层卡片。
- 顶部显示文件与未对应数量；分组导航和表格独立滚动，长文件名单行省略并可悬停查看完整名称；底部固定保存操作与更改状态。关闭未保存的编辑时，提供继续编辑、放弃更改和保存并关闭。

## 层位导入

- 空项目提供“导入 SEG-Y”和“导入层位”两个独立入口。仅导入层位时直接进入层位地图，并支持二维层位剖面、三维曲面与切片交线、时间图、差值图、A–B 层位剖面及各类图件保存与恢复。保留分组、对应、配色、显隐和线条样式；范围与时间位置来自实际层位坐标。无 SEG-Y 时隐藏地震显示、振幅读数及振幅色标，禁用振幅着色；数据面板不展示虚构的地震采样信息。
- 已有地震数据时入口为“切换 SEG-Y”，在当前项目内更换数据源，保留项目名称、层位、显示设置和图件；重新打开项目时恢复最后使用的数据源。
- 沿用层位管理的字号、表格、字段与固定底部操作，按“数据与分组 / 层位对应 / 确认导入”推进。
- 首步左侧为独立滚动的文件清单，右侧选择已有或新分组，确认整批文件使用的数据列；数据预览标明来源文件及各列用途。重复或无效的数据列阻止继续。
- 对应页复用层位管理的编辑器。未应用的预览必须先应用或取消，不能直接返回或进入核对页；已应用的对应关系在返回修改时保留。
- 核对页集中展示分组、数据列、文件与层位对应以及颜色来源。已有层位显示当前统一颜色，新层位说明导入时分配，未对应文件显示独立颜色。
- 未分组或未对应的文件可先导入，之后统一整理。选择文件后关闭导入窗口均需确认，提供继续编辑或放弃导入；点击遮罩不关闭，输入法组合输入与长按 Escape 不触发退出；导入失败在窗口内显示原因并保留设置。

## 修改后的验收

其他工作流同样使用 13px 的项目名称、文件名、输入值与操作按钮，12px 的说明、字段标签与状态。项目列表的名称通过字重与字号区分于数据文件说明，选中行统一引用 `--primary-soft`。

文件路径文本框沿用公共字体、细描边与焦点轮廓；小型弹窗的主要按钮至少 36px 高，队列行操作至少 32px。导出弹窗挂载在页面顶层，标题与底部操作固定，仅中间设置区滚动，避免主画布的裁切边界遮挡弹窗。

项目名称按钮直接进入“项目管理”，只保留“全部项目 / 最近删除”两个范围，不再叠加操作下拉菜单。选中行只改变管理对象，“已打开”标记与底栏当前项目明确工作区归属；打开或返回工作区是独立的主要动作。列表展示数据类型与层位数量，仅在文件缺失或配置损坏时显示异常，不用“待检查”暗示健康项目有问题。

所选项目区域提供重命名、创建副本和删除，均直接作用于该项目；当前项目另提供“关闭项目”。新建与创建副本的提交动作明确为“创建并打开”，副本页展示来源以及复制范围。重命名、取消、返回后保留列表选择与搜索；子页只占用一个弹窗。顶部保存状态与立即保存合为一个控件，自动保存为默认行为，保留 Ctrl / ⌘ + S。

关闭项目先保存并返回起始页，项目仍在列表。删除确认显示项目名称与影响，默认聚焦“取消”；移至“最近删除”后可恢复设置和图件，原始数据保留。删除当前项目后项目管理仍可继续使用；恢复后回到全部项目并选中恢复项，由用户决定打开。“最近删除”提供恢复与彻底删除：恢复为主要动作，彻底删除放在所选项目区域并使用危险色；单独确认中明确名称、清理范围和无法恢复，默认聚焦取消。清理失败保留“清理未完成”状态，可重试彻底删除，禁用恢复。窗口标题和底部动作固定，中间内容独立滚动。

所有图件（二维、三维、层位地图、A–B 剖面）的保存窗口不单独提供“项目 / 数据集名称”输入项。文件名输入框直接显示最终名称，支持编辑并通过“自动命名”恢复默认；重名序号直接体现在输入框中，不再重复显示“将保存为”提示。扩展名单独显示并随格式切换。默认名称只保留图件类型与层位或剖面位置，例如 `2D_IL12`、`层位图_T24_DTW`、`AB剖面_IL10-12_XL30-33`；尺寸、色标、数据集等信息保留在元数据中。同名文件自动增加 `_02`、`_03` 序号。空名称、名称确认中或确认失败时禁止提交，排队和生成任务显示已确认的文件名。

2D、3D 和层位地图中的层位功能入口均命名为“层位管理”。

二维、三维和 A–B 剖面的底部不重复展示层位文件列表，名称、颜色及显隐统一在侧栏管理。坐标、振幅读数与色标使用固定 44px 高的信息区；空间不足时在区内横向滚动，不换行挤占绘图区。仅层位项目不显示空白读数区。

二维与 A–B 剖面的“固定横纵比”只约束绘图区形状。鼠标框选允许任意长宽，缩放后完整显示所选坐标范围；窗口调整时保持所选范围与绘图区比例。关闭固定比例后恢复填满可用区域。

二维与 A–B 剖面在缩放和平移期间保留全域导航底图，精细数据到达后替换当前区域。底图与精细图共用色阶和极性，已绘制的精细图完整遮挡底图并保留空值；读数及导出继续使用原始数据。历史插值窗口仅作过渡，最终按当前视窗重新采样。

地图等值线的线宽、间隔与数值标签归入“显示方式”，仅在等值线或叠加模式下出现。剖面设置展开后始终展示 A、B 端点与横纵比，允许提前配置；有 SEG-Y 时另显示地震显示入口。“绘制剖面线”只控制地图上的线与拾取交互，不决定下方设置的显隐。
