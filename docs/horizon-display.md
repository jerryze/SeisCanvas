# 层位显示与平滑

二维层位曲线通过 Plotly Scatter/SVG 绘制。原始层位坐标、显示曲线和鼠标拾取各自独立，显示平滑不写回原始文件。

## 两种平滑方式

| 设置 | 默认 | 作用 |
| --- | --- | --- |
| 平滑曲线（PCHIP） | 关闭 | 保形连接节点，经过给定节点，不降低时间量化幅度 |
| SG 平滑显示 | 关闭，窗口 7 道 | 平滑节点时间，可选 5、7、11、15 道，二次多项式 |

两项设置作用于二维可见层位，并随工作状态保存。SG 降低节点时间抖动，PCHIP 平顺节点之间的连接；可分别启用或组合使用。关闭 SG 后恢复原始节点。

## PCHIP 连接

前端 `frontend/src/components/SeismicViewer2D/horizonCurve.ts` 实现保形分段三次 Hermite 插值。导数根据完整曲线计算，显示节点根据可见范围和绘图区像素宽度生成，原始节点始终保留。缩放不改变曲线形状。

缺失点分段处理，不跨缺口连接。单点原样保留，两点退化为直线；重复或逆序横坐标保留原始连接，不擅自平均、删除拾取点。PCHIP 不能恢复原始时间量化时已丢失的细节。

## SG 时间平滑

`backend/horizon_display.py` 使用 `scipy.signal.savgol_filter`，固定 `polyorder=2`、`mode="interp"`，只处理有效段的时间列。输出使用独立浮点数组，不取整，也不重新对齐地震采样时间。

无效时间、重复横坐标及不规则道间距分隔有效段，不跨缺口滤波。短段采用不大于段长的奇数窗口，不足 3 点时保留原始值。完整剖面的计算结果可缓存，屏幕和导出随后按可见范围裁剪。

## 拾取与导出

原始点负责标记、拾取及坐标查询；SG 显示数据单独返回，过期参数的结果不用于当前曲线。地震背景、波形和原始 SEG-Y 振幅查询不受层位平滑影响。

二维 PNG、SVG、PDF 图件导出共用后端 SG 算法；SG 与 PCHIP 同时开启时，导出对 SG 节点进行 PCHIP 连接。SVG/PDF 中层位仍为矢量线条。导出队列保留保存时的图件，后续调整设置不会修改已入队文件。

## 维护与验证

相关实现位于 `backend/horizon_display.py`、`backend/rendering.py` 和 `frontend/src/components/SeismicViewer2D/`。数值与显示回归覆盖节点保持、短段、缺口、重复坐标、缓存失效和导出一致性，见 `tests/test_horizon_sg.py` 及前端曲线测试。
